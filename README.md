# 英雄杀世界模式助手

本项目保存当前 Windows／雷电模拟器上的助手代码与研究记录，作为后续功能开发及切换账号问题的版本基线。使用 Python/Tkinter 提供界面，通过 Frida 桥接已登录游戏进程，在游戏主线程调用原生 Lua 业务函数；请求使用客户端已有连接与登录上下文。没有修改原 APK。

## 当前功能

- 自动训练弓兵、骑兵、步兵、斥候；训练加速默认不启用，兵营升级时不训练。
- 动态英雄名单、状态展示、指定英雄恢复，以及采集共用恢复调度。
- 资源清单采集、粮木铁存量与预期收入分配、联盟采集。
- 按服务器额度补充打野队伍、区域查询、原生默认编队和胜券在握检查。
- 烽火台救援、怪物、资源、宝藏分别勾选；宝藏只消耗现有斥候，不购买。
- 烽火台占用包含返城队伍；满额或明确6395拒绝时保持开启，按服务器阶段时间和推送等待空位。结果未知仍停止，不自动重发。
- iOS 微信原生扫码登录；账号变化后清空旧显示、重建连接，读取当前角色与地图数据，请求沿用原生SDK认证。
- 账号管理：按角色名、等级、系统和QQ/微信显示本机保存的账号；票据使用当前Windows用户DPAPI加密，按已验证的重启客户端方案切换，失效时提示重新扫码。

各自动总开关启动及重新读取账号后默认关闭；本次会话手动开启打野后，才恢复地图刷新时刻自动开启规则。当前功能详情优先参考代码及 `docs/superpowers/specs/` 中较新的设计；`auto_infantry/使用说明.txt` 和早期研究记录包含历史行为。

## 本机运行环境

- Windows，Python 3.12（Tkinter 随官方 Windows Python 安装提供）。
- 雷电模拟器 `emulator-5554`，ADB 当前路径为 `E:\leidian\LDPlayer9\adb.exe`。
- 游戏包名 `com.qqgame.mic`，当前只接受4.31.0／versionCode 431000017。
- 已有的模拟器 root 环境及匹配的 Frida 服务17.25.2；服务文件位置见 `auto_infantry/bootstrap.py`。
- 当前入口使用 `.analysis-tools/pyenv/Scripts/pythonw.exe`。换电脑后需核对 ADB、设备及服务二进制位置，这些设置尚未做成通用配置。

在项目根目录准备 Python 环境：

```powershell
py -3.12 -m venv .analysis-tools/pyenv
.analysis-tools/pyenv/Scripts/python.exe -m pip install -r requirements.txt
```

匹配的 Android x86_64 Frida 服务文件需自行放入 `.analysis-tools/frida-server-17.25.2-android-x86_64`，或已部署到模拟器的对应路径。仓库不包含这些二进制。

保持模拟器及已登录游戏运行，进入西游幻境并等地图加载完成，再双击 `Start-AutoInfantry.vbs`。重启时先关闭旧助手窗口，再打开此入口，不要同时启动两个助手。

## 账号保存和切换

顶部「账号管理」可保存当前已登录角色、切换选中账号，或按安卓/iOS、QQ/微信扫码更新票据。切换会停止自动功能、重启客户端、恢复对应原生SDK档案；请本人勾选原生协议，助手等待勾选后只发起一次本地票据登录。成功后进入西游幻境即可重新读取当前账号数据；所有自动功能、训练加速与打野定时开启均不恢复，需本人重新开启。过期/拒绝或恢复超时会提示重新扫码，不自动循环登录。

整个档案加密保存在 `%LOCALAPPDATA%\REA_YXS\accounts\`，文件名不含账号原始标识；不保存密码，不写入Git或操作日志。只适用于当前Windows用户及本机模拟器环境。先前验证成功的本机安卓QQ和iOS微信实验备份会导入账号列表，后续扫码或保存更新同一稳定账号，不按昵称重复新增。安卓QQ／iOS微信往返已验证；其他原生平台组合的实际授权结果以服务器为准。

助手顶部的「iOS 微信扫码登录」会先停止自动操作、关闭旧连接并重启客户端。请本人勾选登录页协议，等待二维码出现后用苹果角色对应的微信扫码授权；成功后自动加密保存。二维码只请求一次，等待超时不自动重发。授权后进入西游幻境，助手主动拉取兵营数据，成功后初始化当前账号其他数据。

「重新读取当前账号」停止当前自动功能、清空旧数据并重建连接，也可取消扫码等待。检测到账号／地图会话变化时会自动重建，等待地图加载；每次重建的总开关与训练加速勾选均关闭。旧计时与界面消息不会应用到新会话；只检查本地上下文，不增加固定网络轮询。

保存的资源清单、英雄与烽火台类型选择继续共用，不按账号分文件；不会因为保留选择而自动开启功能。只有明确保存或成功扫码/切换后才更新加密票据；扫码失败不覆盖原有记录。取消等待会停止后续认证，已完成的SDK存储恢复不会再自动登录。

## 灵台试炼

「灵台试炼」页的「自动灵台试炼」默认关闭。开启时关闭其他自动功能；无本轮名单时，从服务器确认可参加试炼的英雄中按战力选前三人，已有三人名单则沿用。每层使用其中最强可出战英雄，满足游戏原生时间或回合条件后跳过；确认本场服务器结算胜利才继续下一层。

战败、拒绝或结果不明立即关闭，保留游戏界面供本人处理；不自动复活、不重试、不翻牌或分享。关闭后不再挑战或跳过，已经接受的战斗不会取消。本人处理完并返回地图后，助手重新读取当前账号，其他自动功能仍关闭。阶段推进读取现有响应及本地状态，不增加固定服务器轮询。

## 军报定时领取

「军报」页的「每两小时自动领取军报」默认关闭。开启后等待两小时，查询一次完整列表；有可领取奖励时使用原生一键领取，再确认结果。无奖励跳过，每轮完成后再计时两小时；不使用数量阈值或红点触发，不删除军报，等待期间无网络查询。

界面显示下次检查时间、最近确认时间、总条数和各分类待领奖励数。关闭、换号、重启、断线或开启灵台试炼会取消计时，重新开启从两小时重新计算，不补跑错过的周期。领取拒绝或结果不明时关闭，不自动重发；结果不明时核对游戏并重新读取账号。日志归属检查仅读取有界尾部，避免累计日志过大造成首次读取超时。
