# 英雄杀世界模式助手

本项目保存当前 Windows／雷电模拟器上的助手代码与研究记录，作为后续功能开发及切换账号问题的版本基线。使用 Python/Tkinter 提供界面，通过 Frida 桥接已登录游戏进程，在游戏主线程调用原生 Lua 业务函数；请求使用客户端已有连接与登录上下文。没有修改原 APK。

## 当前功能

- 自动训练弓兵、骑兵、步兵、斥候；训练加速默认不启用，兵营升级时不训练。
- 动态英雄名单、状态展示、指定英雄恢复，以及采集共用恢复调度。
- 资源清单采集、粮木铁存量与预期收入分配、联盟采集。
- 按服务器额度补充打野队伍、区域查询、原生默认编队和胜券在握检查。
- 烽火台救援、怪物、资源、宝藏分别勾选；宝藏只消耗现有斥候，不购买。
- 烽火台占用包含返城队伍；满额或明确6395拒绝时保持开启，按服务器阶段时间和推送等待空位。结果未知仍停止，不自动重发。
- iOS 微信原生扫码登录；账号变化后清空旧显示、重建连接，读取当前角色与地图数据，请求沿用原生SDK认证。
- 账号管理：按角色名、等级、系统和QQ/微信显示本机保存的账号；本机票据使用当前Windows用户DPAPI加密，迁移使用免密码的明文JSON，兼容导入旧加密文件，失效时提示重新扫码。
- 玩家武将查询：在“玩家武将查询”页输入数字用户ID并点击“查询武将”，显示服务器返回的最强武将及展示武将，包含战力、等级、星级、宝具与装备。助手查询时保留当前游戏页面，不打开个人信息页；游戏内手动查看仍正常，同时手动查询会取消助手本次查询，避免资料串用。该规则也适用于联盟成员和本图记录的玩家查询。每次点击才请求，不定时刷新；换号清空结果，超时不自动重试，不推断完整武将名单。
- 单独按用户ID查询只要求已登录游戏，不要求进入西游幻境或等待地图初始化；使用临时大厅连接并校验登录身份，与联盟查询、扫描和导出串行。缓存命中直接复用，可在玩家查询页清空缓存。当前账号有已确认的地图上下文时沿用该图缓存；从未加载地图时使用当前区服的大厅缓存（地图ID为0），不借用其他账号遗留的地图上下文。账号切换会取消旧查询，迟到响应不显示在新账号界面。联盟成员、地图扫描及导出仍要求正确地图。
- 联盟成员查询：“联盟成员”页按“左侧联盟 → 中间玩家 → 右侧武将资料”浏览。点击联盟立即显示该盟本地已发现玩家，不请求服务器；“更新联盟人数”手动加载联盟，“加载服务器成员”单独查询所选联盟的原生成员名单。选中玩家后点击“查询选中玩家”或双击玩家才查询武将。其他联盟服务器名单标注为公开资料，不保证完整；不批量查询武将、不定时刷新，换号清空界面。
- 本图玩家索引：在“联盟成员”页手动点击“搜索本图用户”，按地图配置分区域搜索一轮，逐区去重保存身份、昵称、联盟和坐标；可停止并保留已保存记录。按区服及地图ID分文件，用本机Windows用户加密保存；重启只加载本地记录，按联盟筛选也不请求服务器，点击某个玩家才查询武将。未发现的玩家不会被删除，不承诺完整名单，不增加固定轮询。
- 联盟Excel导出：右键左侧联盟，选择“导出Excel（已记录成员）”并指定保存位置，才逐人查询该盟本地已记录成员；不重新扫描或加载完整名单。一人一行，横向排列最强武将、三个展示武将及各自战力、等级、星级、宝具和装备，未返回字段明确标记。可点“停止导出”；手动查询冲突、超时、换号或断线停止后续请求，保留部分结果并标注未查询成员。服务器明确拒绝的成员保留错误码后继续下一人；不自动重试、不增加固定轮询，不导出票据或内部身份字段。
- 玩家资料缓存：成功查询后按区服、地图保存本机加密缓存；用户ID查询、联盟成员查询和Excel导出再次命中时直接使用本地资料，不请求玩家详情接口。界面及Excel标记“本地缓存”并保留原确认时间，不自动过期刷新。“清空资料缓存”只清空当前区服/地图的玩家武将资料，不删除地图成员、联盟、坐标或登录票据；需要更新装备时先清空再查询。Excel另含文本格式的公开用户ID列和数字格式的最强武将战力列。
- 联盟人数对照：左侧联盟列表并列显示接口人数、本地已发现人数和差额，选中联盟时显示人数更新时间及本地记录时间。仅手动“更新联盟人数”更新接口人数并随地图索引保存；搜索地图不额外刷新人数，重启加载旧统计。差额不判错、不据此认定主城被毁或删人；本地超过接口人数时提示归属或人数可能变化，未知接口人数显示“未查询”。

各自动总开关启动及重新读取账号后默认关闭；本次会话手动开启打野后，才恢复地图刷新时刻自动开启规则。当前功能详情优先参考代码及 `docs/superpowers/specs/` 中较新的设计；`auto_infantry/使用说明.txt` 和早期研究记录包含历史行为。

## 本机运行环境

- Windows，Python 3.12（Tkinter 随官方 Windows Python 安装提供）。
- 雷电模拟器 `emulator-5554`，优先使用 `E:\leidian\LDPlayer14\adb.exe`，未安装时兼容原 `LDPlayer9` 路径；可用环境变量 `REA_ADB` 指定其他安装位置。
- 游戏包名 `com.qqgame.mic`。支持 4.31.0（`431000017`）和 5.1.0（`501000073`），按安装包构建号检查。
- 已有的模拟器 root 环境及电脑端、模拟器端一致的 Frida 17.26.2；支持新版雷电 Android14 的 Houdini ARM 转译连接。服务文件位置见 `auto_infantry/bootstrap.py`。
- 当前入口使用 `.analysis-tools/pyenv/Scripts/pythonw.exe`。换电脑后，先启动雷电，再到助手右上角「雷电设置」选择该电脑雷电安装目录里的 `adb.exe` 和在线的主雷电实例。保存后重新打开助手。路径和实例编号保存在本机 `%LOCALAPPDATA%\REA_YXS\emulator.json`。

在项目根目录准备 Python 环境：

```powershell
py -3.12 -m venv .analysis-tools/pyenv
.analysis-tools/pyenv/Scripts/python.exe -m pip install -r requirements.txt
```

模拟器和本机都缺少匹配的 Android x86_64 服务文件时，助手显示「下载 Frida 17.26.2」。点击后从官方发行页下载、校验并解压到 `.analysis-tools/frida-server-17.26.2-android-x86_64`，然后通过 ADB 部署并重新连接。以后可复用该文件。雷电实例需在线且已启用 Root；连接失败时请先根据提示检查实例。也可以事先把解压后的文件放到上述路径。[Frida 17.26.2 官方发行版](https://github.com/frida/frida/releases/tag/17.26.2)

Android14日志尾部读取显式使用`toybox dd`，兼容新版系统裸`dd`入口返回`no such tool`的情况；仍只读取有界尾部并保留未完成帧，不改为整份日志读取或增加游戏请求。

保持模拟器及已登录游戏运行，进入西游幻境并等地图加载完成，再双击 `Start-AutoInfantry.vbs`。重启时先关闭旧助手窗口，再打开此入口，不要同时启动两个助手。

需要同时使用第二台雷电时，在同一个助手窗口顶部点「＋ 添加雷电」，选中第二台的设备编号。请先在对应模拟器启动游戏并进入西游幻境。第二页提供自动造兵、自动采集、自动打野、联盟采集、英雄属性与恢复、烽火台和军报自动领取。切换标签时两边的任务继续运行，关闭第二页会停止该页任务。

第二页的「切换账号」使用这台雷电自己的账号库。首次可保存已登录角色，或选择平台扫码登录。切号成功后自动开关默认关闭。第二页的资源清单按角色和地图保存，英雄勾选与烽火台类型按角色保存。

## 账号保存和切换

扫码重启准备：先只读检查游戏已保存的 `mNoAutoLogin`。只有唯一且明确为暂停状态时，才跳过对旧客户端 Lua 环境的重复连接，直接走原有重启流程；否则仍须连接旧客户端暂停自动登录。这样旧进程模块不可用时，不会因重复设置一个已生效的开关而卡在重启前。协议仍需本人勾选，不自动重复认证。

顶部「账号管理」可保存当前已登录角色、切换选中账号，或按安卓/iOS、QQ/微信扫码更新票据。切换会停止自动功能、重启客户端、恢复对应原生SDK档案；请本人勾选原生协议，助手等待勾选后只发起一次本地票据登录。成功后进入西游幻境即可重新读取当前账号数据；所有自动功能、训练加速与打野定时开启均不恢复，需本人重新开启。过期/拒绝或恢复超时会提示重新扫码，不自动循环登录。

整个档案加密保存在 `%LOCALAPPDATA%\REA_YXS\accounts\`，文件名不含账号原始标识；不保存密码，不写入Git或操作日志。直接复制 `.dpapi` 文件通常无法在另一台电脑解密，跨电脑请使用下述迁移功能。先前验证成功的本机安卓QQ和iOS微信实验备份会导入账号列表，后续扫码或保存更新同一稳定账号，不按昵称重复新增。安卓QQ／iOS微信往返已验证；其他原生平台组合的实际授权结果以服务器为准。

### 明文JSON迁移账号

1. 工作电脑打开「账号管理」，按 Ctrl / Shift 选择要搬走的账号，点击「明文导出选中账号」。每批支持1～50个账号，总数据最多64MiB。
2. 选择 `.yxsaccounts` 文件保存位置，即可生成UTF-8明文JSON，无需迁移密码。文件包含登录凭据，请妥善保管。
3. 家里电脑配置好同版本助手及依赖，打开「账号管理 → 导入账号迁移文件」，选择文件即可。旧版加密文件仍需输入原迁移密码。导入只更新本机账号库，票据会使用该电脑当前Windows用户的DPAPI加密，不自动登录、切换当前游戏账号或开启自动功能。
4. 导入后手动选择单个账号切换；票据失效或设备环境不被SDK接受时提示重新扫码，不自动重试。已知失效账号导入后仍标记为「需要重新扫码」。

导入/导出会停止当前助手连接及全部自动功能。完成后可切换账号，或点击「取消等待 / 重新读取」重新连接当前账号，开关仍需本人开启。本机已有相同身份的账号一律跳过，不用旧备份覆盖新票据；若确实要替换，请先删除该条本地账号后重新导入。多选时只允许导出，切换和删除要求单选。

明文JSON包含账号资料和SDK票据快照，SDK快照保留游戏自己的存储格式。旧版密码加密文件继续按原格式校验和解密。全部账号数据验证后才保存本机票据，保存先暂存密文再发布，失败时回滚本次新增账号。迁移文件由 `.gitignore` 排除。跨电脑免扫码登录是否可用仍取决于票据及SDK/服务器对设备环境的校验。

### 可移植凭据（跨电脑免重扫）

上面的明文JSON只搬走SDK票据快照，加密列（微信 `access_token / refresh_token / pf / pf_key`，QQ 用 `pay_token` 代替 `refresh_token`）仍是本源电脑 `com.tencent.msdk.a.e`（钥匙来自当前安装的 `WxLoginModel.gk()`）的密文，另一台电脑的SDK解不开，所以只能提示重新扫码。需要「导入后直接切换」时用可移植凭据：

1. 本源电脑把游戏开到登录页，在「账号管理」选中账号后点「导出可移植凭据（含明文Token）」。导出会附加到当前进程、用SDK自身的 `f2` 解出四列明文，并核对 `access_token` 的 SHA256 与账号库记录一致；不一致、列为空或解码失败都不生成文件。
2. `.yxsaccounts` 仍是原来的 format 2 明文JSON，多出 `sdk_plain` 与 `sdk_plain_sha256` 两块；旧版助手导入会忽略它们，新版导入时与本机账号库一样用当前Windows用户DPAPI加密保存。
3. 目标电脑导入后选择该账号切换。切换前助手先用本机SDK的 `f3` 重新加密这些列、回读校验、换掉快照里对应的密文并重算 `db_sha256`，之后才走原有的重启与票据恢复流程；重加密成功后本机只保留本机密文，明文块不再保存。
4. 目标电脑当时没开游戏时，助手会先启动客户端、等模块加载完再重加密，不会跳过。任何一步失败都保持原账号记录，不发起登录。

约束：可移植的是 `access_token`（约2小时）与 `refresh_token`（约30天）。超期、服务器按设备/渠道拒绝（`iRet=2`）仍要重新扫码；两台电脑需同版本游戏与可用的 Frida 服务。文件含明文Token，请自行保管，不要提交到Git或网盘公开链接。

助手顶部的「iOS 微信扫码登录」会先停止自动操作、关闭旧连接并重启客户端。请本人勾选登录页协议，等待二维码出现后用苹果角色对应的微信扫码授权；成功后自动加密保存。二维码只请求一次，等待超时不自动重发。授权后进入西游幻境，助手主动拉取兵营数据，成功后初始化当前账号其他数据。

「重新读取当前账号」停止当前自动功能、清空旧数据并重建连接，也可取消扫码等待。检测到账号／地图会话变化时会自动重建，等待地图加载；每次重建的总开关与训练加速勾选均关闭。旧计时与界面消息不会应用到新会话；只检查本地上下文，不增加固定网络轮询。

保存的资源清单、英雄与烽火台类型选择继续共用，不按账号分文件；不会因为保留选择而自动开启功能。只有明确保存或成功扫码/切换后才更新加密票据；扫码失败不覆盖原有记录。取消等待会停止后续认证，已完成的SDK存储恢复不会再自动登录。

## 灵台试炼

「灵台试炼」页的「自动灵台试炼」默认关闭。开启时关闭其他自动功能；无本轮名单时，从服务器确认可参加试炼的英雄中按战力选前三人，已有三人名单则沿用。每层使用其中最强可出战英雄，满足游戏原生时间或回合条件后跳过；确认本场服务器结算胜利才继续下一层。

战败、拒绝或结果不明立即关闭，保留游戏界面供本人处理；不自动复活、不重试、不翻牌或分享。关闭后不再挑战或跳过，已经接受的战斗不会取消。本人处理完并返回地图后，助手重新读取当前账号，其他自动功能仍关闭。阶段推进读取现有响应及本地状态，不增加固定服务器轮询。

## 军报定时领取

「军报」页的「每两小时自动领取军报」默认关闭。开启后等待两小时，查询一次完整列表；有可领取奖励时使用原生一键领取，再确认结果。无奖励跳过，每轮完成后再计时两小时；不使用数量阈值或红点触发，不删除军报，等待期间无网络查询。

界面显示下次检查时间、最近确认时间、总条数和各分类待领奖励数。关闭、换号、重启、断线或开启灵台试炼会取消计时，重新开启从两小时重新计算，不补跑错过的周期。领取拒绝或结果不明时关闭，不自动重发；结果不明时核对游戏并重新读取账号。日志归属检查仅读取有界尾部，避免累计日志过大造成首次读取超时。

## 宝具替换

「宝具替换」页用于把指定英雄对局内的宝具换成目录里的宝具（当前：天狼 49034、傲剑 49036、侠胆 49037）。**设置可以在游戏大厅完成，不需要先进西游幻境**：该功能用自己独立的桥接，不等待地图加载。

用法：输入英雄名 → 点「解析英雄名」（按本机英雄配置表把名字解析成基础 id，`星级×1000+基础id` 的变体都算命中）→ 选最多两个主印 → 勾「进入对局后自动替换宝具」。之后进闯关，助手约 0.8 秒内完成核对与替换，只在客户端内存里改当前对局的英雄卡：不发请求、不改存档，退出对局或重连即恢复。

只填空着的槽位：已装备的宝具不会被覆盖，槽位不够时直接停止并提示。技能 id、宝具类型、星级与触发率全部取自本机游戏配置行，不写死。每次替换前的原值会留一份，「还原本次替换」可以写回。

同一局里副将不要带相同宝具，否则两张英雄卡会共用同一个技能实例（`CSkillMgr._skillCache` 按技能 id 共享）。

## 战斗聊天

“战斗聊天”页输入普通文字后，只有点击“发送一次”才调用原生 `ChatController.sendChatMsg` 一次。最多40个GBK字节（约20个汉字或40个英文字母）；空内容、换行、控制字符和原生文字接口不支持的字符不会提交。回车、切换页签、重启助手均不发送，不保存正文或配置自动发送。

每次点击使用独立临时桥接，不要求西游幻境地图就绪，也不重绑造兵/采集连接。发送前及确认期间核对当前账号、战斗阶段、房间和桌号；选将、观战、结算、大厅不发送。保留游戏原生五秒重复消息检查，不修改游戏输入框的启用状态或玩法聊天配置。

仅在观察到对应10006发送请求，以及本账号、同正文、同类型的10007服务器回推后显示已确认；不据此保证其他玩家一定看到。结果不明、房间变化或超时不自动重试；正文保留给本人核对。确认等待只读取既有日志和本地状态，空闲期间不建立聊天连接、不轮询服务器。切换账号清空草稿，旧账号结果不更新新账号界面。部分玩法虽可由客户端原生接口发出，最终是否接受仍由服务器决定。

## 日常提交

玩家武将查询当前无法获取其他玩家的全部装备和印方案，具体表现及验证边界见[已知问题](docs/已知问题.md)。

```powershell
git status
git diff
git add <本次修改的文件或目录>
git commit -m "说明本次改动"
git push origin master
```

运行日志和本机偏好不会进入提交。新增诊断文件或大文件时，先检查暂存列表，避免使用强制添加把本地数据带进仓库。
