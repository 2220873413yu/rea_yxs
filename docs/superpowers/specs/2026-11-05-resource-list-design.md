# 多坐标资源清单（用户已确认）

清单保存显示坐标，不保存资源余量、资源标识或消费开关。按用户最新要求，只保留资源清单界面，移除资源、等级、单点坐标及范围筛选。清单中的粮木铁按实时类型选择对应最快英雄，各等级均可；不受原20格范围限制。编辑清单通过独立窗口逐行录入 x,y，校验整数、去重，原子保存；重启恢复清单，自动采集仍默认关闭。运行中不允许编辑清单。

候选以距离升序、坐标和标识稳定排序。缓存只负责定位和距离，清单中的余量和占用必须实时查询。4级及以上余量小于40000跳过，等于40000可采；1至3级不设最低量，但空资源不能出征。按距离逐一查询，取首个符合原生资格、空点、队列、余量条件的目标，再选英雄并合并恢复需求。出征主线程再次检查余量阈值，防止查询后状态变化绕过规则。目标余量不符时不产生该目标的恢复需求。

地图定位先读取已有缓存，再按[采集区域加载方案](2026-11-07-collection-region-loading-design.md)主动定位未缓存的清单坐标，无需用户滑动地图。清单为空禁止开启，最多100个坐标，不擅自修改已有坐标。第一队收到成功响应，并确认本方行动中的队伍、英雄、目标和采集类型后，才允许下一轮检查；实际队列仍有空位就选择另一位可用英雄及合格点，不写死只出一队或超出队列上限。

验证覆盖保存/重载/损坏/重复/无效坐标，混合等级及距离排序，低余量近点跳过后选远点，实时数据覆盖缓存，最终Lua阈值防护，开关关闭与共用恢复已有保护。仅离线模拟消费，不进行实际派兵测试。
