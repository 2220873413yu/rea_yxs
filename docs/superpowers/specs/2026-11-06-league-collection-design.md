# 自动联盟采集

用户已确认：独立开关，启动默认关闭；每次启动主动读取服务器联盟矿和本方部队真实状态。开启后维护一支联盟采集队伍，已有手动派出的队伍也纳入观察。手动撤回不暂停开关，服务器确认回城后继续采集。

从本联盟建筑列表发现当前资源矿，不依赖视野缓存或固定坐标。每次出征前重新确认库存、共享空位和英雄状态，使用目标返回的采集速度排序，优先速度高、负重大、行军快的空闲英雄；带兵沿用原生默认方案。本功能不主动使用恢复道具，不自动建设资源矿。

只用服务器部队阶段结束时间安排一次性检查，保留本方部队及联盟矿变化的被动通知、手动检查，不做固定网络轮询。无矿、矿空、共享位置满或暂无英雄时等待变化。无法确认的出征不重发，独立关闭联盟采集。关闭后不发新请求，已有行动不撤销。

助手增加联盟采集页，显示矿坐标、种类、实时余量、共享占用，以及本方英雄、阶段、服务器阶段结束时间、下次检查时间和最后确认时间。关闭时保留上次确认值并取消检查时间。

验证覆盖启动只读、关闭不出征、已有队伍不重复派出、手动撤回后返城再派、服务器阶段计时、空矿无轮询、响应归属、开关隔离和原生默认带兵。在线验证限于只读，不自动开启功能。

## 使用与验证

关闭旧助手，再双击工作区根目录的 `Start-AutoInfantry.vbs`。联盟采集放在独立页签，启动先核对服务器再开放控制；自动开关默认关闭。可在关闭状态点击“检查服务器状态”只读刷新。勾选后才允许出征。

已通过186项Python测试与9组JS开关隔离场景。生产查询模块的只读在线验证读取到了联盟铁矿(125,72)、余量7409085、共享占用3/30、本方联盟队伍为空；没有开启任何私有验证桥的消费权限或发起出征。尚未实际运行新增自动循环，原生联盟出征协议此前已单次验证成功。
