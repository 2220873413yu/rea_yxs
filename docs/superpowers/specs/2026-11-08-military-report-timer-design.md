# 军报每两小时自动领取

用户选择以固定两小时周期代替数量阈值或军报红点触发。独立开关默认关闭；开启只建立本地计时，满两小时首次检查，每轮处理结束后再计时两小时。没有可领奖励则跳过；关闭、换号、重启、断线或开启灵台试炼后取消，不补跑错过周期。

到期时复用串行Worker：11045原生全量列表查询，确认新响应后按原生模板类型3/5/6、iGotStatus=0且奖励列表非空统计。存在可领奖励才提交11046原生一键领取；原生函数参数顺序为(emailId=0, mailType=0, getAll=1)，协议字段顺序为(emailId=0, getAll=1, mailType=0)。收到本次请求对应的成功回包后查询一次列表展示当前状态，不因仍有新奖励而立即再次领取。

刷新与领取共享独立report桥接权限及代次，关开切换取消旧请求；领取令牌绑定当前地图、账号、刚确认的响应及10秒时效，用后即失效。人工相同请求混入、超时、错误回包、账号变化或无法确认时关闭，不自动重发。领取结果不明禁止直接重新开启，须核对并重新读取账号。不删除军报，不发送清红点请求，不打开领奖动画或分享。

等待期间仅比较本地monotonic截止时间，不查询服务器。每个请求读取日志有界尾部并定位最后完整记录，避免长期运行后的大日志初始化超时。界面显示下次检查北京时间、最近确认时间、各分类条数与可领奖励数；未查询时明确显示尚未查询，不显示旧账号数据。

验证：定时边界、无奖励跳过、取消、过时代次、领取不明禁止重发、原生参数顺序、鲜活列表、账号地图改变、军报UI默认关闭和有界日志读取均有测试。403项Python/Lua测试与13组桥接检查通过。正式Connection实机只读全量查询成功，返回300条、可领奖励39条（军事35、内政4、事件0）；未在验证时实际领取，也未跳过两小时等待强行启动领取。
