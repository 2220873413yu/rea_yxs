# 打野暂时跳过目标后继续搜索

用户反馈：范围内有可打目标、出征空闲，但面板停在“英雄/兵力不可用或战力数据不完整”。

根因：临时等待列表的最小距离圈被用作整个扫描和候选检查的上限；同时，跳过目标后仅在同圈还有候选时安排继续检查。近处一个临时不可用目标可挡住远处已发现目标或尚未查询的区域。回归测试以近处数据不完整、远处可用阵容复现，只查询第一个目标。

修复：等待列表仅排除其自身坐标，不限制搜索距离。跳过后，如有其他候选或未查询区域，继续有限扫描；保持由近到远、设置半径、原生视野、空闲及胜券在握检查。所有候选和区域耗尽后按已有服务器时间或状态变化等待，不增加固定网络轮询。明确满编也打不过的坐标仍加入本轮忽略名单；暂时不可用不加入该名单。

验证：80项打野相关测试通过。新增覆盖已缓存远处目标、未查询远处区域和所有目标暂不可用后无反复查询。未在游戏中实际出征。
