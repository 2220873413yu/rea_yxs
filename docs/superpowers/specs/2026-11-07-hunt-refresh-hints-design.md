# 按地图配置的刷新时刻触发打野重扫

按用户确认的方案实现。读取当前地图配置sRefreshTime，复用现有hunt_watch本地读取携带的服务器时钟，按北京时间计算下一配置时刻。西游幻境当前配置为00/03/06/09/12/15/18/21/24时，但代码不把每3小时写死。24:00与00:00归并，下一次时刻始终在当前服务器时间之后；首次开启仍由原有启动检查执行，不追补过去所有时刻。

跨过配置时刻只设置一个待重扫标记。缓存显示满队时不因该提示新增部队查询，也不查区域；等既有部队状态通知、服务器阶段截止时间或明确的空位变化唤醒。容量未知时最多沿用一次当前检查确认，不固定重查。等待期间跨过更多刷新时刻仍合并为一个待办，时钟前进多小时不逐次补发。

仅在服务器确认可用出征额度后消费标记：清掉旧发现记录、已完成目标过滤及临时等待，区域进度回到起点，由近到远重新取得实际服务器目标。已出征／待跳过队伍继续跟踪，英雄与目标预留仍有效；本轮战力不足坐标忽略规则保留。用刷新轮次区分旧队伍的归还，避免旧轮次的目标ID在归还时再次遮蔽新发现。

时间表只代表客户端配置的检查提示，不保证服务器在该时刻已产生新怪。没有目标时仍进入事件／截止时间等待；所有出征仍需重新确认有视野、空闲、在范围内和胜券在握。关闭打野清除本轮重扫待办，不让旧回调继续扫描；后续新增的[刷新时刻自动开启规则](2026-11-07-hunt-scheduled-enable-design.md)会在下一配置时刻重新开启，结果不明除外。未增加固定网络轮询，原有本地watch频率不变。
