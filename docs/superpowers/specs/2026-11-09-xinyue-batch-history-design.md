# 心悦一键签到与本地领取记录

用户确认：遍历已添加账号，处理G分普通签到、普通周礼包、每日礼包和免费抽奖；能领才领、已领取跳过，并保存本地领取记录。2026-11-09已确认批量预查、统一确认后串行执行的方案。

## 执行流程

1. 点击一键签到后固定本轮账号清单，逐账号查询四项状态、绑定角色和配置，显示汇总。
2. 用户统一确认本次账号、角色与可领项目后串行执行。每项仍由原客户端重新查询并校验身份/配置/资格，复用原持久化防重复记录。
3. 不包括七天游戏签到、G分兑换、广告、激活、购买和改绑定。单项手动入口继续可用，批量运行期间互斥。
4. 已领、资格不足、非零费用跳过。查询失败跳过该项；领取结果不明则停止该账号剩余项目，继续其他账号。领取失败不重试。
5. 停止按钮只取消后续任务，不取消已发出的请求，也不丢弃其核对结果。启动无自动领取或固定轮询。

## 记录

本地SQLite保存账号昵称/本地账号键、角色显示名、北京时间、领取项目、状态、实际奖品和安全结果说明，不保存Token、Cookie、OpenID或原始响应。

提交前写入处理中记录并落盘，结束更新为成功、跳过、失败、待确认；进程中断遗留的处理中记录按待确认显示。记录故障发生在提交前则禁止提交，提交后记录更新失败不重发。

批量和单项入口（包括既有手动兑换、七天签到）统一接入。查询不冒充领取记录。抽奖候选奖池不冒充实际奖品；实际奖品未解析时标明待核对，签到余额变化另列说明。历史旧操作不编造领取时间或补造成功记录。

界面增加一键签到/停止批量、领取记录窗口，记录列表按最新时间排序，支持刷新和状态筛选。启动读取本地历史无网络请求。不得为了验证批处理重复领取真实账号奖励；优先离线测试，再用只读预查与取消统一确认核对界面。
