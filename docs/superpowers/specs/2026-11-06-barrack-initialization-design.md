# 切号后空兵营缓存初始化修复（用户已确认）

根因：runtime.lua安装末尾调用status，要求兵营缓存已存在；Worker在Connection.open成功后才refresh，切号清空缓存时无法到达主动查询步骤。

修正：基础Lua接口安装只返回安装完成，不读取兵营状态；新增barrack_probe允许缓存nil，并观察响应代次。Connection.open安装基础接口后先记录当前代次，再发送一次11028查询，最多等待6秒的新代次成功响应；随后校验三种兵种状态，再加载英雄、采集接口。旧成功缓存不可替代新响应，失败/超时停止且不重发。Worker不再在open后重复发送相同初始化查询。

所有消费门控默认关闭，UI三个自动开关默认关闭不变。保留游戏版本、地图已加载及同一地图上下文保护，不实现自动换号、运行中地图重连或账号偏好隔离。助手可先在大厅打开：本地每秒读取地图就绪标记、不发服务器请求，显示等待进入西游幻境；地图加载完成后才绑定当前上下文并查询。关闭窗口可取消等待，不会自行点击进入地图。此等待仅作用于启动阶段。

验证：105项Python/Lua测试及6组桥接测试通过。实际生产Lua+Python模拟空缓存安装、一次主动查询成功、旧缓存无新响应超时、失败响应及地图变化发送前停止，均未启用消费。当前真实游戏map_loaded=false、兵营缓存nil，未执行实际新账号初始化成功验证，未操作游戏进入地图。

后续验证完成：用户于大厅等待后手动进入西游幻境，当前stage=SLGMapMainSceneStage、ready=true。独立命名空间运行实际Connection.initialize_barracks：初始received=false/seq0，单次查询后seq1成功，弓兵47、骑兵39、步兵47，训练道具6203；随后读到66英雄，地图玩家标识与当前登录标识一致。全程门控关闭，无消费。107项Python/Lua测试、6组桥接测试通过，补充大厅等待和取消验证；窗口布局及默认关闭开关验证通过。
