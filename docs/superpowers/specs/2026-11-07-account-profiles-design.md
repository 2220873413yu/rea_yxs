# 加密账号保存与重启切换

用户确认沿用已实测成功的重启恢复方案，加入账号保存与切换、角色资料显示、当前账号重读和失效后扫码提示。自动功能默认关闭。

## 界面与边界

顶部新增「账号管理」，独立窗口显示角色名、等级、安卓/iOS、QQ/微信及票据状态。提供保存当前账号、切换选中账号、按平台扫码更新。保存按SDK账号标识、授权平台、移动平台及协议区标识去重，昵称不作为唯一键。原有资源清单及英雄选择继续保留，但不会自动开启功能。

保留并导入此前两份本机DPAPI实验备份。推荐复用已验证的SDK数据库及四个SDK登录选择字段；只存Token字符串无法完整恢复，运行中直接修改SDK缓存的热切换也未通过，不采用。

## 数据与模块

票据存放于当前Windows用户的LocalAppData/REA_YXS/accounts，整个账号档案使用DPAPI加密。文件名为稳定账号键摘要，不包含Token或OpenID。公开界面事件仅包含角色元数据，凭据不进入日志、界面事件或Git。保存和切换均串行撤销旧工作线程；账号代次继续隔离旧事件、队伍、计时与打野定时开启。

存储模块负责校验、加密、原子更新及列表；Android传输模块负责内存读取、SQLite WAL合并、停止进程与文件恢复；账号服务负责保存和原生认证；LoginSession负责所有权与工作线程重建。UI不直接接触票据内容。

## 切换流程

先解密并校验目标，再关闭自动功能、退出旧工作线程。原生暂停启动自动登录并检查设置持久化，停止游戏，确认进程退出，恢复目标SDK档案与登录选择字段，重新启动。修改SDK存储期间不允许另一个请求并行进入；写入失败尝试恢复修改前文件，不携带半写入档案启动。

启动阶段只通过ADB只读检查进程与原生模块，加载稳定后才接入Frida，不主动加载原生库。登录页等待用户本人勾选协议，助手仅检查本地状态。恢复目标平台及云端iOS标记后，一次调用原生本地票据登录，验证SDK账号与服务器TUserID、平台一致。昵称和等级从成功响应更新，允许角色正常升级或更名。

独立的账号操作互斥锁覆盖整个保存/重启/恢复/认证过程，包括桥接暂时断开期间；普通连接也检查该锁，防止另一助手实例插入。关闭窗口时先取消并等待事务安全退出，主界面保持响应，不能让daemon线程被Python退出截断。

成功后更新加密档案，建立全新默认关闭的Worker，等待用户进入西游幻境，主动查询兵营成功后加载其他数据。不自动进入地图、出征或消耗道具。不增加固定游戏服务器轮询。

## 失败、扫码与取消

账号管理提供“删除选中账号”，确认框明确显示角色、系统与授权方式，默认取消。删除只移除选中身份的本机DPAPI档案，不操作游戏连接、SDK登录数据或服务器角色；保存、切换、扫码期间禁用删除。先持久化该稳定摘要的删除标记，再移除票据；旧实验备份导入与删除共用账号互斥锁，并跳过已标记身份，防止重启后复活。标记不含凭据，不影响之后本人重新扫码保存该身份。删除失败刷新实际列表并提示，不误删其他记录。用户已明确授权删除iOS微信“旅行”并重新扫码验证。

SDK记录缺失、认证拒绝或票据无效时标记需要扫码；查询超时显示未完成/可能失效，不冒充已确认过期，不自动重放登录。扫码更新使用对应原生平台入口，在新进程中由用户授权，成功后保存同一稳定账号键。扫码失败不覆盖原有票据，登录到其他账号时作为新账号保存并明确显示实际角色。

恢复期间可通过重新读取当前账号取消等待。取消撤销后续认证与自动操作；已经完成的SDK存储恢复不会再自动登录。关键文件写入为完整事务，取消不在两文件提交之间截断。使用已保存票据恢复时，原生mNoAutoLogin在发起选定平台认证前恢复原值；扫码登录则在整个授权等待期间保持暂停，服务器确认身份成功后才恢复原值。失败或取消时停止原生重连并保持暂停，不清空SDK授权、不覆盖其他已保存账号。
