# 同角色、同区服、同地图打野重连恢复

用户已确认：只恢复断线前开启的本轮自动打野，其他功能默认关闭。不增加固定网络轮询。

## 边界

原生重连开始时拦截后续助手请求；原生重登成功并重新加载地图后，核对原有角色完整身份、地图 ID 和区服 ID。身份留在游戏进程，只向电脑返回核对结果。登录响应对象变化本身不能证明换号。

仅在打野没有未确认出征、没有未确认跳过时保存恢复检查点。检查点包含范围、已确认部队、忽略坐标、已完成目标和主城位置，不包含凭据。检查点仅在内存中有效，不跨助手重启恢复。

复用现有串行连接替换。等待原生重连通知和本地地图就绪，最长 45 秒，可取消；等待过程只检查本地状态，不发网络请求。真正切号、换图、缺少重连成功通知、等待超时均停止。

## 恢复

建立新适配器后，一次重新查询英雄和本方部队，要求新鲜且队伍额度已知。按原部队 ID、英雄 ID、目标 ID 和行动类型逐队匹配。仍在行动的队伍仅重新登记，不能重新出征；已返回且英雄没有别的部队的队伍移出跟踪。身份或归属不一致时停止。

恢复沿用忽略名单、已完成目标、已成功跳过标记；地图区域缓存重新建立。已完成跳过不再提交，未确认跳过或出征不恢复。只接管之前确认的队伍，不接管人工派遣队伍；人工队伍仍占用动态服务器额度。

发送边界：桥接层第一行身份栅栏明确拒绝时，原生行动函数尚未执行，可以撤销本次未发送标记；RPC 超时或缺少回执不能使用该规则。已取得匹配的出征成功回执、随后刷新断线的队伍，保留成功回执并加入恢复检查点，不重新出征。跳过请求若已发送但没有确认响应，始终停止。

## 验证

离线运行真实 Lua 与 Python 路径，覆盖同角色重连、角色/区服/地图变化、无原生成功通知、旧地图缓存、取消/超时、部队返回、部队归属变化、保留忽略名单和未知请求不恢复。使用模拟连接验证没有出征和跳过重放。真实环境只读确认回调声明与安装兼容性，不用真实断线、战斗或消耗资源验证。
