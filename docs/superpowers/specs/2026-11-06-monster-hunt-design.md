# 自动打野第一版

用户已确认：同时只出一支队伍；以主城为中心由近及远，只攻击有视野、空闲且原生评估为“我方超强，胜券在握”的普通野怪。按合法带兵上限枚举，选择满足评估的最少小兵，到达后调用游戏原生跳过战斗并核对结算。

默认关闭。搜索半径从5格按5格扩大，默认上限20格，可在关闭时调整；每次出征重新优先近处。仅读取已加载地图缓存，不移动地图、不修改视野、不声称已扫描未加载区域。无可打目标显示等待，支持手动检查。缺英雄或队伍暂满不扩大范围。

用户后续要求将可配置范围的最大值由100提高到200格，默认仍为20格。100是助手原有的本地输入校验边界，不是服务器下发或已验证的游戏距离限制；界面、Python参数和Lua候选/发令校验统一支持1～200。保持原有近处优先、视野、空闲、胜券在握和队伍上限规则，不新增固定轮询。

英雄从最新服务器候选中选择，跳过冷却、出战、活动占用和数据不明者，不为打野自动使用恢复道具。不增加固定服务器轮询：启动、服务器阶段时间、被动状态变化、地图/视野候选变化、英雄冷却到期或手动检查触发。读取本地缓存变化不访问服务器。

打野与采集、训练、恢复共用一个串行工作线程，出征前在游戏主线程最终校验。独立打野开关与世代撤销门控制出征和跳过，关闭立即撤销未发送操作，不撤回既有军队。只跳过助手本轮已确认派出的队伍；已有其他普通打野队伍时等待，不接管手动战斗。

每次出征只发送一次，归属匹配英雄、目标及军队响应；不明结果停止且不重发。跳过同样只发送一次，必须核对队伍ID、目标、阶段及月卡原生跳过权限。服务器拒绝停止并显示错误码。切换地图/账号使绑定失效并停止。

界面显示搜索范围、候选/等待原因、队伍英雄与目标、阶段及服务器时间。单元验证覆盖最少带兵、弱方提示、视野/状态竞态、单队限制、停止世代、响应归属、到达跳过和到期去重。真实运行环境默认只读验证，自动开关保持关闭。
