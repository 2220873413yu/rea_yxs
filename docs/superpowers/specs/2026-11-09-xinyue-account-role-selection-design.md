# 心悦账号平台选择与角色绑定

用户已确认：扫码前选择安卓或 iOS、QQ 或微信；登录后查询对应区服、角色，由本人选择并再次确认后绑定。添加过程不签到、领奖、抽奖或兑换。

## 流程

添加账号窗口的两项选择初始为空，未选择不得申请二维码。平台是英雄杀角色平台，不伪造心悦客户端设备。QQ、微信分别使用已验证的官方独立二维码流程，不依赖模拟器。登录票据先 DPAPI 保存，角色查询失败不丢失已取得的票据。

按明确选择的平台请求服务器区服，再按所选区服分页请求角色。区服列表标签与角色记录标签不一致时，两者分别展示，以实际角色记录说明收件区服，不按昵称推断平台。相同角色 ID 在不同平台查询中出现不作为跨平台存在的证明。

收到 400000 时展示原生资料获取说明，由本人确认后调用 UpdateSettingSwitch，GameRole 的 authAction 为 2（仅自己可见），再重新读取列表。拒绝授权保持票据已保存，不绕过授权。

角色列表不默认选中。点击确认绑定再次显示账号、平台、区服、角色；重新查询相同区服核对该角色仍属于当前账号后，调用英雄杀通行证 PassCardBindGameRoleV2 一次。已有相同绑定则只读确认；已有其他绑定或需解绑的情况停止，不自动解绑。回执后只读 GetPassCardV2 核对，不以 HTTP 200 或昵称相同判断成功。

请求提交前保存本地防重复标记，超时或未知结果跨重启禁止重复提交同一绑定。原始回执 DPAPI 保存，Token、OpenID、角色唯一标识不显示或写入明文文档。所有业务请求由点击或当前扫码流程触发，无固定业务轮询。

## 验证

离线测试覆盖 QQ/微信、安卓/iOS 参数、隐私授权、分页、平台不符、跨账号选择、实际绑定请求和核对、未知结果防重、取消不发请求。界面烟测使用模拟服务，不对真实账号提交绑定或领取。

## 已确认的手动受限处理补充

用户另行确认允许加入手动处理当前绑定受限的功能。检查按钮先读取服务器当前绑定的平台与角色，不使用普通选人表里的替代角色。只有再次确认后，先解除礼包绑定，再原样绑定回同一个角色。提交前核对旧快照未变且该角色仍属于本账号；解除后确认绑定为空才发重绑。每种写请求一次，失败或结果不明停止，防重记录跨重启保留；明确告知中途失败可能暂时没有礼包绑定。最后同时验证角色一致与受限标记已清除，不以成功回执代替资格确认。不自动切换角色、签到领奖或兑换。正常绑定按钮遇到同角色受限时也不能误报普通绑定成功。
